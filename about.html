About QR Document Encryptor

🎯 Our Mission

To provide a simple, secure, and user-friendly way to share sensitive documents across devices using QR code encryption.

🔐 Security Features

  • AES-256 Encryption: Military-grade encryption for maximum security
  • Password Protected: Files require a password to decrypt
  • Local Processing: All encryption/decryption happens on your device - no server uploads
  • No Data Logging: We don't store your files or passwords

✨ Key Features

  • 📄 Support for all file types (images, documents, text, etc.)
  • 📱 Cross-device compatibility - decrypt from any device
  • 🌐 No internet required after page load (fully client-side)
  • 💾 Automatic file compression for smaller QR codes
  • 🎨 User-friendly interface
  • 📥 Easy download of encrypted and decrypted files

📊 Supported File Types

Images: JPG, PNG, GIF, BMP, WebP
Documents: PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX
Text: TXT, CSV, JSON, XML
Archives: ZIP, RAR
Maximum file size: 5MB

⚙️ How It Works

  1. Upload your document
  2. Set a strong password
  3. File is encrypted using AES-256
  4. Encrypted data is converted to a QR code
  5. Share the QR code with anyone
  6. They can scan/paste the QR data and enter the password
  7. Original file is downloaded decrypted

💡 Tips for Security

  • Use a strong password with numbers, symbols, and uppercase letters
  • Share the QR code and password through separate channels
  • Don't share QR codes with untrusted sources
  • For sensitive files, consider splitting them before encryption
